# О продукте

## Что это

**claw2** — персональный чат-агент на вашем компьютере: модель + **HSS** (стабилизация диалога) + навыки (skills). Вы пишете обычным языком; агент отвечает, запускает инструменты и при необходимости **сам дописывает себе возможности** (новые навыки), оставаясь под вашим контролем.

Это не облачный SaaS на тысячи пользователей, а **один хозяин — один инстанс**.

Слой [HSS](HSS.md) — то, чем claw2 отличается от простой обёртки над API: устойчивость длинного диалога — свойство приложения, а не только выбранной модели.

## Главный сценарий

1. Открыли приложение (или PWA на телефоне).
2. Написали задачу в чате.
3. Агент ответил текстом, файлами, медиа; при необходимости обновил **динамический сайдбар** с кнопками следующих шагов.
4. На desktop: глобус → **встроенный браузер** (вкладки, поиск, вопрос по выделенному тексту) без ухода во внешний Chrome.
5. При закрытии окна desktop runtime может продолжать работать в трее — удобно для удалённого доступа.
6. При повторяющейся теме (и включённых Insights) агент может **спросить**, связать ли ход с прошлым чатом — без галлюцинаций «мы же обсуждали».

## Интерфейсы

| Интерфейс | Для чего |
|-----------|----------|
| **Desktop** | Основной клиент: чат, кабинет, настройки, трей; **глобус** — [встроенный браузер](How-To/Browser.md) |
| **PWA** (`/pwa/`) | Мобильный доступ к тем же чатам через HTTPS (без встроенного браузера) |
| **Telegram / VK** | Опциональные каналы (настраиваются в кабинете) |

### Встроенный браузер (desktop)

Режим **W** в футере сайдбара: сайт в основной зоне, чат снизу и в оверлее. Модель не сканирует DOM сама — только явное выделение («Спросить ассистента») или ваш текст в поле ввода. Поиск из адресной строки идёт в чат браузера со ссылками (или DuckDuckGo, если поиск не настроен). Подробности: [How-To: браузер](How-To/Browser.md).

## Чем claw2 не является

- Универсальной «платформой всех мессенджеров сразу» — каналы подключаются по мере нужды.
- Публичным сайтом без защиты: удалённый PWA требует **токен доступа**.
- Полноценной заменой Chrome (нет отдельного менеджера паролей claw2, PWA-браузера и т.п.).
