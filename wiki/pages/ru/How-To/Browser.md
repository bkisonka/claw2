# How-To: встроенный браузер

Доступно **только в desktop**. В PWA и обычном браузере кнопка глобуса недоступна или показывает заглушку.

## Вход и выход

Внизу сайдбара:


| Элемент          | Смысл                                      |
| ---------------- | ------------------------------------------ |
| Буква на аватаре | **C** — режим чата; **W** — режим браузера |
| Глобус           | Переключить чат ↔ браузер                  |
| Шестерёнка       | Настройки                                  |


В режиме браузера основная зона — страница; снизу остаётся поле ввода к модели. Лента обычного чата скрыта: ответы модели идут в **оверлей** поверх страницы.

**W — вспомогательный режим** к текущему чату. Сообщения со всех вкладок текущего чата пишутся в **один** CHATID (тот же, что в режиме C). При этом **набор вкладок свой у каждого чата**: «Новый чат» даёт пустой browse-workspace; переключение чата в сайдбаре восстанавливает его вкладки. Новый чат создаётся только кнопкой «Новый чат» (и аналогами), а не закрытием вкладок и не сменой URL.

## Оверлей и история

- Оверлей показывает **полную** историю текущего чата, независимо от вкладки.
- Компактная круглая кнопка в **правом нижнем** углу страницы открывает оверлей, если в чате уже есть сообщения (не только через контекстное меню).
- В ленте между сегментами серфинга — метки **времени и title сайта**, чтобы ориентироваться в диалоге.

## Что умеет chrome

- **Вкладки** — новая, закрыть, переключение; ссылки `target=_blank` и результаты поиска открываются в новой вкладке
- Назад / вперёд / обновить / **стоп** (пока грузится)
- **Домой** — пустая новая вкладка
- Адресная строка: URL, история посещений с подсказками, поиск (см. ниже)
- ★ в строке адреса — добавить/убрать **текущую** страницу в закладки; иконка ленты — список закладок
- Найти на странице (⌘/Ctrl+F), масштаб (± и сброс), печать
- Замок — сведения о сайте (HTTPS, разрешения, очистка данных сайта)
- Полоса **загрузок** при скачивании файлов

Контекстное меню на странице: спросить ассистента по выделению, открыть ссылку / в новой вкладке, сохранить, Inspect.

## Спросить модель о странице

Модель **не видит** всю страницу сама. В контекст попадает только то, что вы явно отправили:

1. Выделите текст на сайте.
2. ПКМ → **Спросить ассистента**.
3. Фрагмент уходит в текущий чат в обёртке внешнего контента; ответ — в оверлее.

Внизу можно написать свой вопрос (в т.ч. после выделения).

## Поиск из адресной строки

Если ввести **не URL**, а текст:

1. При настроенном поиске (Tavily / SearXNG / Other) результаты появляются **в текущем чате** (оверлей) со ссылками.
2. Клик по ссылке → **новая вкладка**.
3. Если поиск не настроен или упал — открывается страница DuckDuckGo.

Чекбокс **«Поиск через LLM в адресной строке»** в [Настройках → Поиск](../Settings.md#поиск-в-интернете-search):

- **Выкл** (по умолчанию) — прямой вызов поискового API, без токенов модели
- **Вкл** — короткий запрос в чат (модель + tool `search`, тратит токены)



## Чего нет (намеренно)

- Отдельного чата на каждую вкладку / URL
- Отдельного «домашнего» URL из настроек
- Полноценного менеджера паролей claw2 (пароли — системный Chromium/ОС)
- Встроенного браузера в PWA
