# Расширение-компаньон

Браузерная сборка не содержит встроенного движка — он и не нужен.
**claw2 companion** — небольшое браузерное расширение (Chromium, Manifest
V3), которое кладёт claw2 на настоящий веб: пилюля на каждой странице,
чат-панель оверлеем, композер прижат к низу, а текст и выделение страницы
прикладываются к каждому вопросу.

## Установка (один раз)

```bash
cd extension
npm install
npm run build      # → extension/dist/
```

Затем в браузере: `chrome://extensions` → включить **Режим разработчика** →
**Загрузить распакованное расширение** → указать `extension/dist`.

## Подключение

Откройте настройки расширения (меню «пазл» → claw2 companion, или иконка на
панели):

- **Gateway URL** — где работает claw2, например `http://127.0.0.1:8080`;
- **Gateway API key** — тот же ключ, что использует веб-интерфейс
  (`CLAW2_GATEWAY_API_KEY` из `.env`).

«Проверить соединение» должен ответить `Connected (claw2 <версия>)`. Ключ
хранится в локальном хранилище расширения и уходит только на шлюз; скрипты
страниц его не видят.

## Использование

- На каждой http(s) странице появляется **пилюля claw2**. Клик — панель:
  сверху история чата этой вкладки, внизу композер.
- Задавайте вопрос: модель получает страницу (адрес, заголовок, до 16к
  текста) и выделение как недоверенный внешний контент — та же изоляция
  `<<<EXT>>>`, что в браузерном режиме desktop-приложения.
- Выделите текст → правый клик → **Ask claw2 about "…"** — панель откроется
  с цитатой.
- Когда модель отвечает `open_browser`, вкладка переходит по ссылке; чат
  продолжается (сессия помнится на вкладку).
- Чат появляется в сайдбаре claw2, привязанный к странице
  (browser_page_key) — как браузерные чаты desktop-версии.

## Заметки

- Расширение ходит на шлюз напрямую; включите `gateway.auth` (API-ключ),
  чтобы соединение было авторизовано — как у веб-интерфейса.
- Firefox и публикация в магазине — в планах; пока Chromium, load unpacked.
