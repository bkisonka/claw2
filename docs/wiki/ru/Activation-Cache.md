# Кэш активации (`.claw-cache`)

Импорт кэша поднимает **сохранённую траекторию активации контекста** прошлого глубокого диалога и на её основе **собирает глубокую структуру текущего чата** — чтобы новое обсуждение стартовало не с пустого поля, а в уже выстроенном контуре темы.

Срабатывает **один раз**: на **первом сообщении нового чата**, если в кабинете выбран `.claw-cache`.

## Что происходит при импорте (по сути)

Файл `.claw-cache` — это слепок удачного диалога. При первом ходе новой сессии runtime:

1. **Поднимает цепочку контекстных векторов** прошлого диалога из `activation/vector.npy` и вшивает её в хронику / контур [HSS](HSS.md) **текущего** чата — тот контур, с которым дальше идёт обсуждение.
2. **Подмешивает фрагмент диалога** до пика глубины (`activation/dialogue.jsonl`) как стартовый контекст к первому запросу — чтобы модель сразу шла в том же ходе рассуждения.

Это **не** скрытые состояния (hidden states / activations) API-модели. При экспорте цепочка строится заново по **тексту** реплик через локальный ContextEncoder (часть HSS) и сохраняется в кэш; при импорте эта траектория seed’ится в структуру нового чата.

Итог: новый чат наследует не «список фактов», а **стартовый контур мышления** прошлого разговора и продолжает углублять тему уже в своей сессии.

## Чем это не является

| Это | Это не |
|-----|--------|
| Цепочка контекстных векторов → контур [HSS](HSS.md) **нового** чата | Hidden states / activations облачной LLM |
| Файл `.claw-cache` (ZIP): экспорт / импорт / выбор в кабинете | Дополнительные веса модели или fine-tuning |
| Один раз в начале **новой** сессии | Повторная подстановка на каждом сообщении |
| Глубинный старт обсуждения | Долговременная память ваших фактов |

Факты по-прежнему из текущего чата, инструментов и памяти. Кэш задаёт **глубинный старт обсуждения**, а не архив ответов.

## Как пользоваться

### 1. Кабинет → Кэш активации

1. Откройте **Кабинет → Кэш активации**.
2. Укажите **каталог кэшей** (папка с файлами `*.claw-cache`) и сохраните.
3. **Импортируйте** файл `.claw-cache` или положите файлы в эту папку сами.
4. **Выберите** один кэш из списка (или «Без кэша»).

Выбор пишется в конфиг. Без каталога / выбора новые чаты стартуют без активации.

### 2. Экспорт из чата

Из удачного глубокого диалога:

1. Откройте меню чата в сайдбаре (⋯ у чата).
2. Выберите **Экспорт в .claw-cache**.
3. Сохраните файл, затем импортируйте во вкладке «Кэш активации» (или положите в каталог кэшей).

Так прошлый диалог становится источником траектории контекста и структуры для следующих обсуждений.

## Чего ждать

- На **первом** сообщении в **новом** чате при выбранном кэше поднимается цепочка контекстных векторов прошлого диалога и формируется глубокая структура **этого** чата; к первому запросу может добавиться короткий стартовый диалог.
- Со **второго** сообщения в том же чате файл кэша **не** перечитывается — дальше работает уже живая структура текущего чата.
- На простое «привет» эффект может быть почти незаметен; на тему, близкую к экспорту, глубина обычно появляется быстрее.
- Новый чат или смена чата — новая сессия: активация снова возможна на первом ходе.

## Чего ждать не стоит

- Это не замена Настройкам, Навыкам или памяти.
- Это не поиск по старым чатам и не копирование всей истории в ленту.
- Слабый или «не в тему» экспорт не сделает модель экспертом сам по себе.
