# How-To: удалённый PWA

Доступ к тем же чатам с телефона через HTTPS. iOS требует доверенный сертификат.

## Подготовка на desktop

1. Кабинет → **Настройки → Удалённый доступ (PWA / HTTPS)**.
2. Задайте **токен доступа PWA** (кнопка «Сгенерировать») и сохраните конфиг. Скопируйте токен — он понадобится на телефоне.
3. Включите DuckDNS: домен и токен с duckdns.org; при необходимости «Обновить IP».
4. Включите подготовку сертификата LE, укажите email; «Получить / обновить сертификат».
5. Включите «Слушать HTTPS», порт (часто **8443**, если 443 занят/без прав), UPnP при домашнем роутере.
6. **Открыть HTTPS-порт** (из настроек или трея). Проверяйте с LTE, не с домашнего Wi‑Fi.

Без токена доступа публичный API закрыт — это нормально.

## На телефоне

1. Safari: `https://ваш-домен.duckdns.org:порт/pwa/` (порт укажите, если не 443).
2. Введите **тот же токен доступа**.
3. «Поделиться» → **На экран «Домой»** для режима как у приложения.

Чаты синхронизируются с desktop (один пользователь `default` на desktop-gateway).

## Типичные сбои

| Симптом | Что проверить |
|---------|----------------|
| Не открывается сайт | HTTPS слушает? UPnP/проброс? IP в DuckDNS? |
| Форма токена / 401 | Верный токен, сохранённый в настройках desktop |
| Старый UI | Обновите `/pwa/`, сбросьте SW / переустановите PWA |
