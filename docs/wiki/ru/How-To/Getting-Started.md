# How-To: первый запуск

## Desktop

1. Установите claw2 (dmg / AppImage / installer) с **[https://claw2.online/download/](https://claw2.online/download/)** или соберите из репозитория (`desktop` → `npm run app`).
2. При первом старте пройдите экран LLM: ключ API и при необходимости base URL / модель.
3. Откроется чат. Напишите простой запрос — например «сколько сейчас времени» или «что ты умеешь».
4. Конфиг по умолчанию: `~/.claw2/claw2.desktop.yaml` (на Windows — в профиле пользователя `.claw2`).

### Первый / холодный старт может затянуться

Desktop **не** открывает чат, пока локальный runtime не готов полностью. При первом запуске после установки, после **Выйти** или после перезагрузки ПК splash может висеть **десятки секунд** (часто ~10–15 с на холодном диске Windows). Это нормально:

1. **Отдельный процесс Node** — gateway не внутри UI Electron; его поднимают и ждут ответа `/health`, и только потом показывают главное окно.
2. **Прогрев локального эмбеддера** — при памяти на sqlite поднимается ONNX-модель с диска (`~/.claw2/models`, ~130 МБ), чтобы память/поиск были готовы к первому сообщению.

Последующие запуски обычно заметно быстрее (файлы уже в кэше ОС). Пока приложение в [трее](Tray-and-Background.md), gateway уже работает — повторный «холодный» старт не нужен.

На macOS без подписи Gatekeeper может спросить разрешение — **Open Anyway** в Privacy & Security.
