# Claw2 — справка

Персональный агент, которым вы управляете из чата. Эта wiki — для хозяина приложения, не для разработчиков платформы.

**Сайт:** [https://claw2.online/wiki/](https://claw2.online/wiki/) · [English](../en/Home.md)

> **⚠️ Модели и оплата:** claw2 **сам по себе не даёт** доступ к нейросетям и не включает готовый «облачный чат». Чтобы агент отвечал, вы подключаете **свои** локальные модели (Ollama и т.п.) **или** **свои** API-ключи провайдеров (Yandex и др.) в [Настройках → LLM](Settings.md#llm). Расходы на API и квоты — **на вашей стороне**; приложение их не оплачивает и не субсидирует.

> **Доступ к файлам:** claw2 по умолчанию **не** открывает произвольные папки на диске. Какими путями могут пользоваться навыки на хосте, решаете **вы** через настройку **Host FS access** (Доступ к ФС хоста) в [Настройках](Settings.md#доступ-к-фс-хоста-host-fs-access).

## Быстрый старт

1. Установите desktop и укажите модель (API key / base URL).
2. Напишите в чате, что нужно сделать — агент может вызвать навык или предложить следующий шаг в сайдбаре.
3. Глобус в футере сайдбара — [встроенный браузер](How-To/Browser.md) (desktop): сайт рядом с чатом, вопрос по выделению.
4. Чтобы пользоваться с телефона: настройте удалённый HTTPS и **токен доступа PWA**, откройте `/pwa/` в Safari.
