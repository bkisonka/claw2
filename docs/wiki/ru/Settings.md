# Настройки

Открываются в desktop: **Личный кабинет → Настройки** (или `Cmd/Ctrl+,`).

Сохранение — на диск. Часть параметров требует **«Сохранить и перезапустить»**. Кнопка **«Проверить подключения»** показывает, живы ли LLM, голос, поиск, картинки, vision.

Без LLM claw2 — пустой экран чата. Остальные секции ниже как раз превращают его в **агента**: навыки на диске, память, поиск, страницы, картинки, каналы, телефон.

## Что включить в первую очередь

| Цель | Секция | Минимум |
|------|--------|---------|
| Ответы в чате | **LLM** | base URL + API key + модель |
| Навыки читают/пишут ваши папки | **Песочница → Host FS** | allowlist с путями или осознанный full |
| Помнит факты между чатами | **Память** | включить (дефолт sqlite + local ONNX) |
| Ищет в интернете | **Инструменты → поиск** | Tavily key **или** SearXNG URL |
| Открывает URL по запросу | **Web Fetch** | обычно хватает дефолтов |
| Рисует картинки | **Инструменты → генерация изображений** | URL + модель + enable |
| Голос в чате / каналах | **Голос** | local voice или remote STT/TTS |
| Telegram / VK | **Каналы** | токен + enable |
| Звонки | **SIP** | ВАТС + optional Realtime |
| Телефон с улицы | **Удалённый доступ** | токен PWA + HTTPS |

Онбординг при первом запуске настраивает LLM. Личность и список навыков — **другие вкладки** кабинета (не эта страница).

### Конфиденциальность (отдельная вкладка)

Облачный API без защиты = утечка данных с машины, в том числе персональных. Вкладка **Личный кабинет → Конфиденциальность**:

1. Включите **«Маскировать ПДн перед облачным API»**.
2. При необходимости добавьте **свои правила** (keyword / regex).
3. Проверьте превью: исходный текст → плейсхолдеры вроде `[PII_EMAIL_1]`.

В чате вы по-прежнему видите обычный текст; в облако уходит замаскированное. Для локальных моделей (localhost) маскирование по умолчанию не применяется — данные и так не уходят с машины.

**Картинки и PDF (фаза 2):** опциональный native `privacy-ocr-sidecar`. Во вкладке Конфиденциальность — статус sidecar, `multimodalBackend` (`auto` / `sidecar` / `off`), лимит размера и таймаут OCR. При включённом privacy и отсутствии sidecar (`auto`) вложения **блокируются** до удалённого LLM; текстовое маскирование работает как раньше. Подробнее: `docs/privacy-multimodal.md`.

## LLM

Без рабочей модели чат не отвечает.

| Поле | Зачем |
|------|--------|
| Провайдер | Логический id (`openai`, `ollama`, …) — дефолты и совместимость |
| Модель | Имя у провайдера (`gpt-4o-mini`, `llama3.2`, …) |
| Base URL | Корень OpenAI-compatible API (`https://api.openai.com/v1`, `http://127.0.0.1:11434/v1`) |
| API Key | Секрет; сохранённый показывается как `***` |
| Thinking | Reasoning-блоки у моделей, которые их умеют |
| Режим системного промпта | `full` — полный; `compact` — короче, экономит контекст |
| Макс. токенов ответа | Потолок длины ответа |

После смены ключа/URL — сохранить и при необходимости перезапустить; «Проверить подключения» → LLM зелёный.

## Голос

Нужен для кнопки «нажми и говори» в чате, озвучки ответов и (часто) SIP pipeline / каналов.

### STT и TTS

Два независимых блока: **локальный** voice-сервис или **удалённый** OpenAI-compatible API.

| Режим | STT | TTS |
|-------|-----|-----|
| Локальный | URL вида `http://127.0.0.1:9000/stt` | `…/tts`; движок Silero (CPU/Mac) или MOSS (NVIDIA) |
| Удалённый | Base URL + модель (`whisper-1`) + API key | Base URL + модель (`tts-1`) + voice id + API key |

Без CUDA выбор MOSS автоматически уходит в Silero. How-To: [Голос](How-To/Voice.md).

## Телефон (SIP / ВАТС)

Даёт инструмент **`phone_call`**: регистрация на виртуальной АТС, звонки, перевод на оператора. Для обычного текстового чата не обязателен.

### База SIP

1. Включить SIP / `phone_call`.
2. Сервер, порт (часто 5060), логин, пароль; домен — если отличается от сервера.
3. Display name, локальный UDP-порт, публичный IP (NAT) — по необходимости.
4. URI оператора — куда переводить человека.
5. Автоответ — входящие без ручного «ответить».

Для pipeline-режима (listen/say) дополнительно нужны рабочие **Голос → STT/TTS**.

### Realtime (speech-to-speech)

Дуплекс на линии **без** цепочки STT → LLM → TTS. Провайдер:

| Значение | Поведение |
|----------|-----------|
| **Выкл. / Pipeline** | Старый путь `listen` / `say` + batch voice |
| **Yandex** | Рекомендуется для РФ: API-ключ + **folder ID** (IAM опционально) |
| **OpenAI** | Realtime API — удобнее вне РФ |
| **xAI** | Grok Voice — вне РФ |

Ключи Realtime **отдельно** от LLM. «Использовать ключ LLM» — только явным переключателем (обычно для OpenAI).

Дополнительно: модель, голос (`alena`, `alloy`, …), sample rate (часто 24000), опциональный WebSocket URL.

Подробно: [telephony-realtime.md](../../telephony-realtime.md) в репозитории.

### SIP media backend

| Режим | Смысл |
|-------|--------|
| **Node** | Встроенный SIP/RTP в процессе |
| **Sidecar** | Отдельный native RTP (часто linux/amd64); путь к бинарю или `~/.claw2/sip-media-sidecar` |
| **Auto** | Sidecar, если бинарь найден, иначе Node **без ошибки** |

Статус в UI: работает / не найден / fallback. Realtime **не требует** sidecar; sidecar — про качество RTP. Исходящий `dial` поддерживается и в **node**, и в **sidecar** (SMED Dial).

Runbook: [telephony-lab-runbook.md](../../telephony-lab-runbook.md).

## Память

Долговременные факты между сессиями (эмбеддинги + поиск по чанкам).

1. **Включить память.**
2. Happy path desktop: бэкенд **sqlite**, эмбеддинги **local** (ONNX скачается в `~/.claw2/models` при первом recall).
3. Лимиты: макс. чанков в хранилище и сколько подмешивать в промпт за ход.

**Расширенные:** Chroma URL/коллекция, HTTP-эмбеддинги (Ollama и т.п.). Смена модели эмбеддингов обычно требует wipe БД памяти.

Без памяти агент «забывает» между чатами всё, что не в текущем окне и не в личности.

## Инсайты между диалогами

Умеренный Linker: предлагает связь текущего хода с **конкретным** прошлым чатом (или незакрытым тредом), без выдуманных «мы же обсуждали».

1. Режим: **Выкл** / **Спросить** (по умолчанию) / **Авто**.
2. Лучше работает с **Памятью** и/или **Проектами** (digests соседних чатов).
3. В ask: компактный оффер «Показать» / «Скрыть»; после принятия — короткий текст (cheap pass) и опционально inject в следующий ход модели.
4. «Открыть чат» переключает на тот sessionId.

Подробности: `docs/plans/dialogue-insights.md`.

## Инструменты

Секция объединяет **поиск** и **генерацию изображений**. Если ничего не настроено — соответствующих tools у модели нет.

### Поиск в интернете (`search`)

Модель передаёт запрос; claw2 выбирает бэкенд и возвращает заголовки, ссылки, сниппеты.

#### Провайдер (селектор)

| Значение | Поведение |
|----------|-----------|
| **auto** | Tavily → SearXNG → Other; пропускает пустые/выключенные |
| **только Tavily** | Только Tavily |
| **только SearXNG** | Только SearXNG |
| **Другой…** | Только свой SearXNG-совместимый endpoint |

При **auto** сбой одного бэкенда → следующий; при жёстком выборе — нет.

#### Поиск через LLM в адресной строке браузера

Чекбокс `tools.search.useLlmInWeb` (по умолчанию выкл):

- **Вкл** — текст без URL из адресной строки уходит в чат браузера (модель + tool `search`, тратит токены); ответ со ссылками в overlay.
- **Выкл** — прямой вызов Tavily/SearXNG/Other без LLM; результаты со ссылками в том же чате браузера.
- Если поиск не настроен или упал — fallback на страницу DuckDuckGo.

Подробнее про режим браузера: [How-To: встроенный браузер](How-To/Browser.md).

#### Tavily

Облачный Search API: ключ `tvly-…` (или `env:TAVILY_API_KEY`), глубина `basic` / `advanced` / `fast` / `ultra-fast`. В части сетей возможен **403** даже с верным ключом — тогда SearXNG / Other.

#### SearXNG

Self-hosted или любой JSON API: `GET {url}/search?q=…&format=json`. URL + опциональный API key.

#### Другой… (Other)

Тот же протокол, что SearXNG, но **отдельный** блок — второй инстанс или «всегда только свой URL».

Переключатели **Enable** на каждом блоке решают участие в **auto**.

### Генерация изображений (`generate_image`)

Без этого блока модель не рисует картинки в чат.

| Поле | Смысл |
|------|--------|
| Base URL | Images API (Ollama/OpenAI) или локальный SD-сервис |
| Модель | Напр. `x/z-image-turbo` |
| API-ключ | Часто `ollama` для локального Ollama |
| Режим API | **auto** / **openai** (Images API) / **txt2img** (локальный SD) |
| Включить | Без галочки инструмент скрыт |

После настройки — «Проверить подключения» по images.

## Web Fetch

Инструмент **`web_fetch`**: скачать страницу по URL и отдать текст в контекст (не путать с поиском).

| Поле | Смысл (типичные дефолты) |
|------|---------------------------|
| Таймаут (мс) | Сколько ждать ответа HTTP (~15000) |
| Макс. размер тела (байт) | Сколько скачивать (~1e6) |
| Макс. символов контекста | Сколько текста уходит в модель (~8000) |

Крутить имеет смысл при больших страницах или медленной сети. Без секции поиск всё равно может давать ссылки, но «открой и прочитай» слабее.

## Vision

Распознавание лица с камеры для изоляции памяти по пользователю.

1. Включить распознавание.
2. URL сервиса `/recognize` (часто на том же voice-хосте).

Без URL и сервиса галочка бесполезна.

## Telegram

1. Включить бота, вставить токен от @BotFather.
2. Опционально proxy только для Bot API.
3. Опционально отдельные STT/TTS URL канала; пусто — общие из **Голос**.
4. «Отвечать голосом» + лимит символов для TTS.

Пишете боту — отвечает тот же агент, что в desktop-чате (с учётом памяти/навыков).

---

## VK

1. Включить бота.
2. Access Token сообщества + числовой `group_id`.
3. Голос канала — по аналогии с Telegram (URL / reply with voice / max chars).

## Песочница навыков

Как выполняется код skills (`run_agent`).

### Docker vs хост

| Режим | Когда |
|-------|--------|
| **useDocker = false** (типичный desktop) | Node `--permission` на хосте; нужен **Host FS** |
| **useDocker = true** | Контейнер; нужен Docker Desktop и образ |
| **elevated** | Отдельный чувствительный флаг запуска на хосте вне обычной схемы |

Таймаут (мс) — принудительная остановка зависшего навыка.

### Доступ к ФС хоста (Host FS access)

Управляется **вами**. Имеет смысл при `useDocker=false`.

| Режим | Что может навык |
|-------|-----------------|
| **По умолчанию** | Чтение `agents/` (+ uploads), запись только `agents/output` |
| **Allowlist** | То же + ваши пути чтения/записи (по строке, можно `~/…`) |
| **Полный доступ (*)** | Вся ФС через `--allow-fs-*`; **без** `child_process` |

Расширенный доступ — риск. Без allowlist/full агент **не** видит произвольные папки Документов/Рабочего стола: остаётся «чат + то, что в agents/».

## Gateway

Локальный HTTP API runtime (чат, tools).

| Поле | Смысл |
|------|--------|
| Порт | Если занят — смените |
| Авторизация API | Токен для запросов; важно при доступе не только с loopback |

Desktop Electron ходит на свой runtime. С телефона — см. удалённый доступ, не «откройте порт в мир без токена».

## Удалённый доступ (PWA / HTTPS)

Чтобы пользоваться с телефона по HTTPS:

1. **Токен доступа PWA** — секрет входа с интернета (сгенерировать / скопировать).
2. DuckDNS: домен + токен, интервал обновления IP.
3. Let's Encrypt (DNS-01), email; staging — только для теста.
4. Слушать HTTPS-порт (443 или 8443), UPnP при необходимости.
5. «Открыть HTTPS» из настроек или трея; опция открывать при скрытии в трей.

Статус внизу секции: DDNS, сертификат, HTTPS, UPnP.

Пошагово: [Удалённый PWA](How-To/Remote-PWA.md).
