# cla-signatures — Contributor License Agreement signatures

Branch for storing signed CLAs (see cla/CLA-individual.md and
cla/CLA-corporate.md on main).

Rules:

- One signature — one commit. Add the file under `cla-signatures/` and name
  it `cla-signatures/CLA-individual-<github-username>.md` or
  `cla-signatures/CLA-corporate-<company-slug>.md`.
- The signature includes: full name, e-mail, GitHub username, date, and a
  typed full-name signature.
- A signature covers all future contributions of the signer; earlier
  PRs/issues are covered only if listed in the signature.
- Contributors link the signed file in the description of each PR; PRs
  without a signed CLA are not accepted.
